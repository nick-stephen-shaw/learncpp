# Identifier naming rules & best practices
- The identifier cannot be named a keyword
- The identifier may contain only letter, numbers, and underscore -- no spaces, special symbols (excluding underscore)
- The identifier may not start with a number, only a letter or underscore
- c++ is case sensitive nValue =! nvalue

Common convention
- variable names begin with a lowercase letter; if the identifier is a single word the entire thing is to be written in lowercase letters
- Function names also follow the above protocol
- Identifiers that start with a capital letter are typically reserved for user-defined class-types
- If the identifier is two or more words, you can use snake or camel case
	- snake_case
	- camelCase
- Avoid abbreviations
- Avoid using overcomplex names for trivial variables
