Local variables exist only within a function, as opposed to global variables
Function parameters are also considered local variables

They are created when a function begins and are destroyed when the function is completed

Scope is a compiler-time property

If an identifier is usable it is considered in-scope
If an identifier is unusable it is considered out-of-scope

Local variables defined in one function are not usable in another function even if they are still active

It's best practice to define local variables as close as possible to their first use case

Function parameters vs. local variables
- Use a parameter when the function call will pass values for initialization
- Use a local variable in all other cases

Values provided from return by value functions are considered temporary values and are destroyed after the expression they are used in
