We use a return statement / expression to return a value to a function

main() being special has some specific rules:
- Main must return an integer -- typically 0
- Main must not be called upon by another function (C allows this)

main is not always the first function executed. Global variables are initialized before, so if there exists a function which must be executed to initialize a global variable then it will be executed prior to main 

The return from main is often referred to as the status code, exit code, or return code, and usually 0 is used to represent the program has been ran successfully. 

C++ standard library uses:
- 0 or EXIT_SUCCESS
- EXIT_FAILURE

If a value-returning function does not return a value, it will result in undefined behaviour. 
Any function is value-returning with the exception of void functions

main will automatically return 0 if no instruction is provided, but it is still best practice to add the return expression nonetheless for consistency and to show intent

For each time a function is called it may only return a single value

*Remember:* ***Don't repeat yourself***
If repetitive behaviour can be simplified using functions, it is usually best practice to do so. 

Functions provide a mechanism of doing such

After a return expression the function terminates
