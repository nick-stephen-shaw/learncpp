A functions is a reusable set of statements designed to do a particular job

All programs must have a main() function, but as programs get larger cramming all the code into main() will lead to difficult to work with and worse code. Functions allow the programmer to split the code into smaller, more organized modules

The C++ standard library comes with some functions, although it is common practice to write your own functions. 

Functions the user wrote are called user-defined functions

The function header includes the return type and the function name:
ie) int main()
- Return type: integer
- Function name: main

Then between { } is the entire function body. 

Functions can call on other functions which call on other function, etc...
However, functions cannot be nested, meaning a function's definition cannot be inside of another function
