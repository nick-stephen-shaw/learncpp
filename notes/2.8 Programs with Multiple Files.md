How to do it from scratch (using vs Code)

In **tasks.json** change the 'args' to include every .cpp file
ie):
```
"args": [
  "-std=c++20",
  "-g",
  "${fileDirname}/main.cpp",
  "${fileDirname}/add.cpp",
  "-o",
  "${fileDirname}/main"
],
```

In **launch.json**, make sure prelaunchTask matches the task's label
```
"prelaunchTask": "clang++ build all",
```
