A statement is the smallest unit of computation
It is comparable to a sentence

A function is a unit or group of statements which are read in sequential order

**Every C++ program must have a function called main()**
When a program is ran, every statement in main() is executed in sequential order
The program stops running when every statement in main() has been executed, or when it has been purposely aborted 

Note: Many compilers will point to an error being the line after the line the error actually occurred. If you cannot find the error on a line, check the previous.
