Expressions are a sequence of literals, variables, operators, and function calls that calculate a value. The process of evaluating an expression is called an evaluation and 

Even literals are considered expressions that are just evaluated to their literal value

Expressions do not end in semicolons and cannot be evaluated by themselves; instead, they are always part of a statement (which does itself end in a semicolon)

An expression statement is merely an expression followed by a semicolon

When an expression is used as an expression statement any return value is discarded since it is not used
ie) the return value of x = 5; is discarded, which is fine because it is not used; we only used x = 5; for its side effect of assigning 5 to x

You can also make useless expression statements. For example the line 2 +4; compiles but its result is immediately discarded and it produces no useful side effect. Some compilers will give warnings for such

A subexpression is an expression used as an operand for another expression, for example the subexpressions of x = 4 + 5 are x and 4 + 5, and the subexpressions of 4 + 5 are 4 and 5 

A full expression is an expression that is not a subexpression

A compound expression is typically referred to as an expression with two or more uses ofoperators

Statements are used when we want the program to perform an action
Expressions are used when we want the program to evaluate a value
