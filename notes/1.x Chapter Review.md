Statement: A type of instruction which tells the program to perform some action
A function is a set of statements executed in sequential order
Every program must include a function called main. When the program is ran, main() is read in sequential order

Commenting allows the programmer to leave information in the code

Data is information which can be stored, moved, and manipulated. A single piece of data is called a value. 

A variable is a location in memory which is named and can store a value. In order to create a variable we use a definition statement. When the program is ran each defined variable is instantiated. It is best practice to always initialize these variables (using list-initialization)

A data type tells the compiler how to interpret a piece of data into a meaningful value. A common data type is an integer which is a number which can be written without a fractional component (or decimal for simplicity sake)

Copy assignment (using the = operator) can be used to provide a value to an already defined variable.

Specifying an initial value for a variable is initialization. 

std::cout << allows us to output information to the console
std::endl outputs a newline character and flushes the output. '\n' adds a newline without flushing
std::cin >> allows extracting a value from user input in console 

A variable that has not been given a value is uninitialized. The computer will provide it with a garbage value. Uninitialized variables will result in undefined behaviour.
