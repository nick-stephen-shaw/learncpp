A function parameter is a variable used in the header of a function. They work almost identically to variables defined within the function with the key difference that they are initialized by a value provided by the caller of the function

An argument is a value that is in the caller and is given to the function

Sometimes a function will occur in several locations in code. If a parameters is used in some but not in others, you can use an unnamed parameter. You define the type but give no name to the variable. This will allow the compiler to ignore the parameter and compile the code.
