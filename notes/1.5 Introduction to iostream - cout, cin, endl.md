iostream is part of the c++ standard library and allows for input/output functionality

# std::cout
cout means character output
The std::cout variable allows us to output text to the console

Note that the typical "hello, world!" program uses the >> (insertion operator)

It may be useful to think of >> and << as a conveyor belt which moves data in a particular direction

std::cout is buffered


std::endl; both outputs a new line and flushes the buffer. Flushing the buffer can be slow. This is why using '\n' may be better in some use cases, as it creates a new line without flushing the buffer, thus improving performance in some cases. 

Either written as part of existing double quotes, or single quoted by convention

The i/o standard library does not have a way for the console to accept user inputs without them pressing enter. There exists thrid-party libraries if this is desired

std::cin is buffered
std::cin is terminated with a \n character

how std::cin works
- If it is not in a good state, it will abort
- It will ignore leading whitespace
- This is thus discard the pre-existing newline from a previously inputted value


- `std::cin` and `std::cout` always go on the left-hand side of the operator.
- `std::cout` is used to output a value (cout = character output).
- `std::cin` is used to get an input value (cin = character input).
- `<<` is used with `std::cout`, and shows the direction that data is moving. `std::cout << 4` moves the value `4` to the console.
- `>>` is used with `std::cin`, and shows the direction that data is moving. `std::cin >> x` moves the value the user entered from the keyboard into variable `x`.
