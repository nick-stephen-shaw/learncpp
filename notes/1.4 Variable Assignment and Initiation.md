
We assign variables using the assignment operator: "="
It is important to note the different between the assignment operator "=" and the equality operator " == "

Instead of first defining then assigning a value to a variable, it is faster to simply initialize the variable. 
The syntax looks like this: int num {5};
This initiates the variable num, giving it the value 5 

Initialization gives the initial value of a variable

There exists many forms of initialization, some of which are described as follows:
- int a;  -- default initialization, no value
- Traditional initialization:
	- int a = 5; -- copy initialization
	- int a (5); -- direct initialization
- Modern (preferred) initialization:
	- int a {5}; -- direct-list initialization
	- int e {}; -- value initialization

When no value is provided, it is called default initialization

The benefit of using list-initialization is that the compiler is forced to run a diagnosis on whether or not the value can actually be assigned to said variable. 
- Doing int a (4.5); std::cout << a will give you "4"
	- This can lead to problems which are very difficult to catch later on
	- Using list-initialization you will avoid these problems

Instantiation refers to a variable that has been created (allocated) and initialized

If you are including many variables which may be unused, you can use:
- [ [maybe unused] ]
