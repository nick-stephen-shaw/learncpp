Also known as non-value-returning functions

Oftentimes functions will do useful and desired things but we do not care about their return value. Thus return type 'void' is used, telling the compiler not to worry about a return value for this function

It is best practice to avoid putting a return statement in a void function
- An empty return expression: return; is redundant; providing a return value is a compiler error

void functions can only be called in statements/expressions which do not require a value
