Whitespace refers to characters that are used for formatting purposes, primarily tab, newline, and spaces
Primarily used for:
- Separating certain language elements
- Formatting code
- Formatting text

Some language elements require whitespace be used, for example between two keywords
- int x; 
- int main()
It does not matter how much whitespace is used in these cases
- int    x; is just as valid

Newlines are not allowed in quoted text
Quoted text takes whitespace literally

C++ is a whitespace-independent language -- it has very little formatting requirements
