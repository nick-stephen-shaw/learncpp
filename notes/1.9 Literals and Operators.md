Literals -- A fixed value entered directly into the source code 
Also called literal constants
Examples:
- 5
- "Hello, world!"
These are different to variables: x

The number of operands an operator takes as input is called arity

- Unary:
	- An operator acts on one operand. For example "-" on -5 takes the literal 5 and makes it negative 5 
- Binary:
	- An operator acts on two, often called left and right, operands. Examples are most mathematical operators like + or / and the insertion and extraction operators
- Ternary:
	- Operator that acts on three operands. There is only one of these in C++: the conditional operator
- Nullary:
	- Operator acts on zero operands. There is only one of these in C++: the throw operator

Most operators result in a return value. Anything that a function or operator does that is not directly providing a return value is called a side effect. 

Many operators are used primarily for their side effects. 

Many operators it is not obvious what their return values may be. In these cases, like the following
- int x = 5 
- std::cout << 5
They return the left operand. This is done so that they can be chained. For example
- x = y = 5
- x = (y = 5)
- y is returned so x = y after y = 5 therefore x = 5
- Same story with std::cout << "Hello" << "World"
