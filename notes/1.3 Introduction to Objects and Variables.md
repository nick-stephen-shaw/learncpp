**Data:** any information that may be moved, processed, or stored by a computer. 
Programs are merely collections of instructions to manipulate data such that a desirable result is outputted. 

A single piece of data is called a value, or data value

Data can be obtained from: user input, programmer input directly into the program, databases, the internet, etc...

*Note on syntax:*
- X: a number
- 'X': a character
- "X": text (can be 0 or more characters long)

Values that are placed by the programmer directly into the program are called literals

An object with a name is called a variable

An object represents a region in the RAM wherein data can be stored

A definition statement tells the computer that we want to use a variable
- For example: int x;
