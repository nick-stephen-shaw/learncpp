- Organization
	- Reduces complexity -- breaks up larger programs into smaller, more manageable chunks
- Reusability
	- Remember -- try not to write the same code twice. Functions help to avoid unnecessary repetitions 
- Extensibility 
	- If we have to make a change to the code, it being in a function allows for us to only have to make the change once. 
- Abstraction
	- To use a function all you need to know is its name, inputs, outputs, and where it is. In collaborative coding efforts, this is great. 

A function should typically do one and only one job. 
Refactoring is breaking up a function that is too large into smaller parts.
